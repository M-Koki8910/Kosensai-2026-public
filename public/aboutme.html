ABOUT THIS SITE

このサイトについて

高専祭の情報を、見やすく・わかりやすく・もっと楽しめる形で届けるために作られたWebサイトです。

01

サイトの役割

情報を見つけやすくする

高専祭に関するイベント情報、アクセス情報、会場の流れを、必要なときにすぐ確認できるように整理しています。

来場者が使いやすいようにする

スマートフォンでも見やすいレイアウトを意識し、移動や参加を考えた導線で構成しています。

体験を増やす

単なる案内ではなく、スタンプラリーやイベント紹介など、参加体験が生まれるコンテンツを取り入れています。

情報の伝わり方を大切にする

難しすぎない表現とシンプルな見た目を心がけ、誰でも安心して使えるページを目指しました。

02

使っている技術

HTML

ページの全体構造を作り、文章や見出し、リンク、画像を整理して配置しています。

CSS

見た目の統一感や余白、レスポンシブ対応を行い、伝わりやすいレイアウトを整えています。

JavaScript

ページに動きをつけたり、情報の切り替えを行ったりすることで、より体験的なサイトにしています。

サーバー

公開環境で動くようにし、さまざまな機能やデータのやり取りを実際に動かせる形にしています。

03

制作の意図

高専祭には多くの来場者が訪れます。そのときに必要になるのは、ただ情報が載っていることではなく、「どこを見ればいいか」「どこに行けばいいか」をすぐに理解できることです。

そのため、このサイトでは、見た目を派手にしすぎず、情報の見やすさと使いやすさを優先して構成しました。必要な情報にたどり着きやすくし、安心して閲覧できるようにすることを大切にしています。

重要なのは「見やすさ」

企画や情報が多くなるほど、ユーザーが迷いやすくなります。だからこそ、余白を確保し、見出しを整理し、必要な要素をシンプルに並べることが大切です。

04

このサイトが目指しているもの

  • 来場者が迷わず情報を見つけられること
  • 学校の魅力やイベントの雰囲気を自然に伝えること
  • モバイルでも快適に閲覧できること
  • 次の人が改修しやすい構造にすること
「作る」ことの価値

このサイトは、学校のイベントをよりよく伝えるための手段でもあり、技術を使って人に届く形にするための一歩です。
